Online application forms are picky about file formats. Upload a PNG where a JPG is required and you will see "invalid file type", even if the image is perfect. Here is what each format is for and how to handle them.

## The short answer

| What you are uploading | Use |
|---|---|
| Photograph | **JPG / JPEG** |
| Signature, thumb impression, handwritten declaration | **JPG / JPEG** (unless the notice says otherwise) |
| Certificates, mark sheets, caste or income certificates | **PDF** (sometimes JPG) |
| Screenshots or graphics for other uses | PNG |

## JPG (JPEG)

JPG is a "lossy" format designed for photographs. It throws away detail your eye is unlikely to notice, which makes files small. That is exactly what exam portals want: a recognisable photo in 20–50 KB.

- **.jpg and .jpeg are the same format.** If a portal asks for JPEG, a .jpg file is fine.
- Every time you save a JPG again, it loses a little more quality. Always work from the original photo.

## PNG

PNG is "lossless" — it keeps every pixel exactly. That is great for screenshots, logos and text, but a photo saved as PNG is often **five to ten times larger** than the same photo as JPG. Most exam portals do not accept PNG at all.

If your image is a PNG, run it through our [photo resizer](/tools/photo-resizer) or a [compress image](/tools/compress-image-to-50kb) tool — they always output JPG.

Renaming `photo.png` to `photo.jpg` does **not** convert it. The file is still a PNG inside, and some portals detect this.

## HEIC (iPhone photos)

Recent iPhones save photos as HEIC to save space. Many Indian portals do not accept HEIC.

- Easiest fix: open the photo in our tools in Safari — the browser converts it, and you download a JPG.
- Permanent fix: on the iPhone, go to **Settings → Camera → Formats → Most Compatible**. New photos will be saved as JPG.

## WebP

WebP is a modern web format. You may get WebP files when you save an image from a website or WhatsApp web. Treat it like PNG: convert to JPG before uploading.

## PDF

PDF is used for **documents** — certificates, mark sheets, experience letters — because it keeps multiple pages together and text stays sharp. Portals often set a limit like 100 KB, 200 KB or 500 KB per PDF.

Tips for PDF uploads:

- Scan with your phone's document scanner (Google Drive, Files by Google and the iPhone Notes app all have one). These crop and flatten the page automatically.
- Choose **black-and-white or greyscale** for text documents — it reduces the size a lot.
- Combine only the pages the form asks for. An extra blank page can push you over the limit.
- If the form asks for a **JPG of a certificate**, photograph or scan it and use the [compress image](/tools/compress-image-to-100kb) tool to hit the KB limit.

## Format checklist before you upload

1. Read the notice: what format does each upload need?
2. Photos and signatures: JPG, within the KB range and pixel size.
3. Documents: PDF (or JPG if asked), within the size limit, every page readable.
4. File names: short, no spaces or special characters (`photo.jpg`, `sign.jpg`, `10th-marksheet.pdf`).
